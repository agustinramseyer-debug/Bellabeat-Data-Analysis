# 🌸 Estudio de Caso Bellabeat: Análisis de Tendencias de Bienestar

**Certificado Profesional de Análisis de Datos de Google | Proyecto Final (Track 2)**

¡Bienvenido a mi repositorio! Este proyecto es un análisis de datos enfocado en el negocio para Bellabeat, una empresa de alta tecnología que fabrica productos de salud enfocados en la mujer. 

🎯 **Objetivo:** Analizar datos de dispositivos inteligentes de fitness para descubrir tendencias de uso de los consumidores y orientar la futura estrategia de marketing de la empresa.

## 🛠️ Herramientas y Habilidades Técnicas Aplicadas

Para este proyecto, decidí llevar **Microsoft Excel** más allá del uso de hojas de cálculo tradicionales, implementando un flujo completo de Inteligencia de Negocios (BI):

*   **Limpieza de Datos (ETL):** Estandarización de formatos temporales mediante herramientas de texto a columnas, auditoría de nulos y remoción sistemática de duplicados para garantizar la integridad estadística.
*   **Modelado de Datos Relacional (Power Pivot):** Construcción de un ecosistema de datos aislando 33 IDs únicos (Primary Key) para conectar 3 bases de datos transaccionales (Actividad Diaria, Horaria y Sueño) mediante relaciones `1:N`.
*   **Visualización de Datos:** Diseño de un Dashboard corporativo, minimalista y libre de ruido visual, controlado globalmente mediante Slicers conectados al Modelo de Datos.

## 📊 Descubrimientos Clave (Insights)

1.  **Perfil de Actividad (La Caída Dominical):** Los usuarios alcanzan sus picos máximos de actividad los martes y sábados, pero el domingo sufren una caída drástica hacia el sedentarismo (por debajo de los 7,000 pasos).
2.  **El "Horario Prime":** Existe una ventana crítica de alta actividad post-laboral concentrada estrictamente entre las **17:00 y las 19:00 horas**.
3.  **Latencia de Sueño:** Al cruzar variables de descanso, se descubrió un "punto de dolor" (pain point) oculto: los usuarios pasan en promedio **39 minutos en la cama sin lograr dormir** (vigilia nocturna).

*Nota: Para ver cómo estos descubrimientos se tradujeron en estrategias de marketing accionables (Fase Act), visita el Reporte Web enlazado arriba.*
